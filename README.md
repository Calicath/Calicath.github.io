### 项目1：基于区块链的数字病历存证系统
- 仓库地址：[跳转项目](https://github.com/Calicath/blockchain_medical.git)
- 技术栈：
  - 前端开发：React + TypeScript + Tailwind CSS + Vite
  - 区块链开发：Solidity + Hardhat
  - Web3交互：ethers.js + MetaMask
  - 智能合约测试与部署：Hardhat Network

- 项目简介：
  基于区块链智能合约的医疗病历存证和医保发票验证系统，实现医疗数据可信存储与访问权限管理。

- ✅ 身份权限管理：设计患者、医生、管理员3类角色，实现不同身份下的数据访问控制。
- ✅ 智能合约开发：使用Solidity编写病历存证、授权访问等核心业务合约，并通过Hardhat完成编译与部署。
- ✅ Web3交互：前端连接MetaMask钱包，通过ethers.js调用智能合约，实现链上数据读写。
- ✅ 前端页面开发：基于React实现用户交互界面，实现病历上传、授权管理、查询验证等功能。
- 运行方式：README内包含环境配置、合约编译部署、前端启动完整步骤。

### 项目3：基于深度学习的番茄病害识别系统
- 仓库地址：[跳转项目](https://github.com/Calicath/Tomato_Disease_Diagnosis.git)
- 技术栈：
  - 深度学习：TensorFlow + Keras + ResNet50
  - 数据处理：Python + NumPy + Pillow
  - 数据可视化：Matplotlib + Seaborn
  - Web交互：Gradio
  - 开发工具：Jupyter Notebook + Git

- 项目简介：
  基于深度学习图像分类模型的番茄叶片病害识别系统，实现番茄叶片图像自动分类，并通过多维度数据可视化分析模型性能与预测结果。

- ✅ 数据分析与可视化：负责数据集统计分析，通过类别分布图、样本展示等方式分析数据特征。
- ✅ 模型效果评估：实现准确率曲线、损失曲线、混淆矩阵等可视化，分析模型训练过程与分类效果。
- ✅ 预测结果分析：对模型输出结果进行统计，实现Top-3预测类别及置信度可视化展示。
- ✅ 模型解释分析：利用Grad-CAM生成特征关注区域热力图，辅助分析模型识别依据。
- ✅ 交互系统开发：基于Gradio搭建模型展示页面，实现图片上传、预测和结果可视化。
